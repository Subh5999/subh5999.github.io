# Subh Singh — Portfolio

A responsive personal portfolio with a warm ivory, beige and muted-gold palette, refined typography, and subtle scroll animations.

## Files
- `index.html` — page content and sections
- `style.css` — layout, responsive styling, colour palette and animations
- `script.js` — reveal-on-scroll and mobile navigation

## Publish free with GitHub Pages
1. Create a **public** GitHub repository named `subh5999.github.io`.
2. Upload these four files directly into the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub Pages finishes deploying, visit `https://subh5999.github.io/`.

## Before sharing with a selection committee
- Check that your CGPA, semester, course marks and contact details are current.
- Add a PDF resume link if the application asks for one.
- Keep project repositories public and make sure each README explains your contribution and how to run the project.
- Do not describe areas of interest as professional expertise unless you have practical evidence.

The portfolio intentionally presents AI/ML as areas of interest rather than claiming advanced proficiency.
